# Aplicación móvil: decisión pendiente

Esta carpeta reserva la ubicación de la futura aplicación móvil en el repositorio `VestiNova`. No contiene una app ejecutable y no acredita la entrega móvil del segundo parcial.

La aplicación encontrada en `../../fashionstore-mobile/fashionstore-mobile` permanece en su carpeta original. Es un proyecto Flutter con repositorio Git e historial propios y referencias al proyecto heredado. No se copió, movió ni incorporó como implementación nueva de VestiNova.

Antes de añadir código aquí, decidir entre una implementación propia conforme a los requisitos académicos o una adaptación del código heredado con procedencia, atribución y conservación de historial acordadas. También debe recuperarse o resolverse su estado de archivos eliminados sin sobrescribir el trabajo local. No copiar su `.git` como un repositorio anidado ni eliminarlo.

La revisión técnica está en [REVISION_MOVIL.md](../docs/REVISION_MOVIL.md). Las URLs de conexión y los límites de ejecución se documentan en [EJECUCION_Y_API.md](../docs/EJECUCION_Y_API.md). El contrato del backend nuevo está en [CONTRATO_CATALOGO.md](../docs/CONTRATO_CATALOGO.md).
